### 📁 目录结构

```
/usr/share/fonts/
├── cmap/          # 字符映射
├── opentype/      # OpenType 字体(.otf)
│   ├── freefont/  # Free 字体 OTF版本
│   ├── noto/      # Noto 系列 OTF
│   ├── urw-base35/# URW PostScript字体
│   └── mathjax/   # MathJax 数学字体
├── truetype/      # TrueType 字体(.ttf/.ttc)
│   ├── msttcorefonts/  # Windows 核心字体
│   ├── noto/          # Noto 系列 TTF
│   ├── ubuntu/        # Ubuntu 字体
│   ├── dejavu/        # DejaVu 字体
│   ├── liberation/    # Liberation 字体
│   ├── arphic/        # AR PL 中文字体
│   ├── freefont/      # Free 字体 TTF
│   ├── moe/           # 教育部标准字体
│   ├── wps-office/    # WPS Office 字体
│   └── winFonts/      # Windows 字体集合
├── type1/         # Type1 字体
└── X11/encodings/ # X11 编码
```
